3.7 Processing Logic

STEP 1 — FETCH REVISIONS:

SELECT REVNR, REVTY, REVBD, REVED, IWERK, VAPLZ, VAWRK, OBJNR, AUFNR, ZZ_ESLOT_START, ZZ_ESLOT_END FROM T352R INTO TABLE lt_revisions WHERE REVNR IN S_REVNR AND REVTY IN S_REVTY AND REVBD IN S_REVBD AND REVED IN S_REVED AND IWERK IN S_IWERK AND VAPLZ IN S_VAPLZ AND VAWRK IN S_VAWRK. Filter additionally by ZZ_ESLOT_START IN S_ESLOTS AND ZZ_ESLOT_END IN S_ESLOTE.

STEP 2 — FILTER BY STATUS (REL) AND AGE:

FOR ALL ENTRIES IN lt_revisions: SELECT OBJNR, STAT FROM JEST WHERE OBJNR = lt_revisions-OBJNR AND STAT = 'I0002' AND INACT <> 'X'. Additionally filter: REVED ≤ SY-DATUM - P_DAYS (default 60 days).

STEP 3 — GET LINKED NOTIFICATIONS AND ORDERS:

FOR ALL ENTRIES IN lt_released_revisions: SELECT WPID, NOTIFID, ORDER_NO FROM DIWPS_RV_CR WHERE WPID = lt_released_revisions-REVNR. Note: DIWPS_RV_CR field WPID maps to revision number (data element REVNI, CHAR 8).

STEP 4 — CHECK NOTIFICATION STATUS (NOCO = I0072):

For each notification: SELECT QMNUM, OBJNR FROM QMEL WHERE QMNUM = notification-id. Then check JEST for STAT = 'I0072' AND INACT <> 'X'. If ANY notification lacks NOCO → mark revision as 'cannot close', log ZPM_AUTOCOMPLETE 001.

STEP 5 — CHECK ORDER STATUS (CLSD = I0046):

For each order: SELECT AUFNR, OBJNR FROM AUFK WHERE AUFNR = order-no. Then check JEST for STAT = 'I0046' AND INACT <> 'X'. If ANY order lacks CLSD → mark revision as 'cannot close', log ZPM_AUTOCOMPLETE 001.

STEP 6 — CLOSE REVISION (CLSD):

If all notifications NOCO and all orders CLSD: CALL FUNCTION '/AXONEBX/GET_REV_CLOSE' EXPORTING I_REVNR = lv_revnr I_WERKS = lv_iwerk. On success → BAPI_TRANSACTION_COMMIT WAIT='X'. Log ZPM_AUTOCOMPLETE 004. If no linked network (T352R-AUFNR is initial) → Log ZPM_AUTOCOMPLETE 007, continue to next revision.

STEP 7 — CLOSE NETWORK (TECO = I0045):

Get network AUFNR from T352R for the closed revision. Check other revisions linked to same network: SELECT REVNR FROM T325R WHERE AUFNR = lv_network AND REVNR <> current. For each other revision, check JEST for CLSD (I0046). If ALL other revisions CLSD: CALL FUNCTION 'BAPI_BUS2002_SET_STATUS' EXPORTING NUMBER = lv_network SET_SYSTEM_STATUS = 'I0045'. Check RETURN (TYPE BAPIRETURN1 — fields: TYPE, ID, NUMBER, MESSAGE, MESSAGE_V1..V4). On success → COMMIT. Log ZPM_AUTOCOMPLETE 005.

STEP 8 — CLOSE WBS (TECO = I0045):

Get WBS element: SELECT PSPEL FROM AUFK WHERE AUFNR = lv_network. PSPEL is NUMC 8 (data element PS_PSP_ELE). Convert to external format via CONVERSION_EXIT_ABPSP_OUTPUT for BAPI parameter WBS_ELEMENT (PS_POSID, CHAR 24). Check other networks for same WBS. If ALL networks TECO: Populate lt_wbs_status TYPE BAPI_WBS_MNT_SYSTEM_STATUS (WBS_ELEMENT = external, SET_SYSTEM_STATUS = 'TECO'). CALL FUNCTION 'BAPI_BUS2054_SET_STATUS' TABLES I_WBS_SYSTEM_STATUS = lt_wbs_status. Check RETURN. COMMIT. Log ZPM_AUTOCOMPLETE 006.

STEP 9 — EMAIL NOTIFICATION (Plant ECE2 only):

If WBS TECO'd AND T352R-IWERK = 'ECE2': Read distribution list SO15 for EC FI email addresses. Send email via CL_BCS using MO-0595 template. Log ZPM_AUTOCOMPLETE 008 on success, 009 on failure.

STEP 10 — DISPLAY LOG:

Consolidate all messages. Log columns: Revision No | Network No | WBS Element | Step | Status (S/E/W/I) | Message Text. If SY-BATCH = 'X' → output to spool. If foreground → display via CL_SALV_TABLE.

5 Assumptions in Technical Design

1. All service orders are assumed to be closed (CLSD) within 60 days from revision end date — controlled by P_DAYS parameter (default 60).
2. Service Orders and Notifications are linked to Revision via DIWPS_RV_CR table (WPID = Revision Number, data element REVNI, CHAR 8).
3. Network is linked to Revision via T352R-AUFNR field (data element NW_AUFNR, CHAR 12).
4. WBS Element is linked to Network via AUFK-PSPEL field (data element PS_PSP_ELE, NUMC 8).
5. BAPI /AXONEBX/GET_REV_CLOSE is available on target S/4HANA system (Axone partner namespace).
6. Distribution list SO15 for EC FI email recipients is maintained.
7. Email template MO-0595 is available and configured.
8. BAPI_TRANSACTION_COMMIT (WAIT='X') is called after each successful status change.
9. Sequential processing — no parallel processing required.
10. BAPI_BUS2002_SET_STATUS NUMBER parameter typed as BAPI_NETWORK_LIST-NETWORK (NW_AUFNR, CHAR 12).
11. BAPI_BUS2054_SET_STATUS WBS_ELEMENT typed as PS_POSID (CHAR 24, external format — requires CONVERSION_EXIT_ABPSP_OUTPUT).
