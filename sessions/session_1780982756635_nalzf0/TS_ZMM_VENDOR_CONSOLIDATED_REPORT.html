3.7 Processing Logic

Main Processing Steps:

  1. AT SELECTION-SCREEN OUTPUT: Populate listbox values for P_STATUS, P_BLACK, P_BEGRU, P_BEGRU1, P_BRSCH using FM VRM_SET_VALUES
  2. START-OF-SELECTION: Validate mutual exclusivity; Convert listbox keys to text; Load defaults from TVARVC if needed
  3. Data Selection: Primary SELECT from LFA1; FOR ALL ENTRIES from related tables; SORT each result table for binary search
  4. Data Processing: LOOP AT LT_LFA1; Determine STATUS based on SPERR/SPERM/SPERQ; Lookup blacklist from ZVENDOR_BLOCK; Link to BP via CVI_VEND_LINK; Apply secondary filter; APPEND to LT_FINAL
  5. ALV Output: Build field catalog; CALL FUNCTION REUSE_ALV_GRID_DISPLAY

Status Determination: IF SPERR='X' OR SPERM='X' OR SPERQ IS NOT INITIAL then STATUS='INACTIVE' ELSE STATUS='ACTIVE'

Blacklist Determination: READ TABLE ZVENDOR_BLOCK; IF VFLAG='X' then BLACKLISTED='Yes' ELSE BLACKLISTED='No'
