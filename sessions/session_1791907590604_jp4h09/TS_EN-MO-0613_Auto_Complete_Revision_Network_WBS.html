3.2 Validation of Selection Criteria

1. At least one selection criterion must be provided. If all selection fields are empty → display error message ZPM_REVCOMP 009 "No revisions found matching selection criteria" (Type E) and stop processing.

2. P_DAYS: validated as a positive integer > 0. Default value = 60. Non-numeric or negative values raise an error.

3. Date range: If both S_REVBD (start) and S_REVED (end) are provided, start must be <= end date.

4. All selection parameters are optional — allows flexible batch variant configuration.

3.4 Authorization Requirements

Authorization is managed at the batch job scheduling level as per Business Unit (BU) decision. The program does not implement explicit AUTHORITY-CHECK statements. Access control is enforced by:

1. SM36/SM37 job scheduling authorization (S_BTCH_JOB, S_BTCH_ADM)
2. Plant-level PM authorization objects (I_IWERK, I_BEGRP) already assigned to the batch user profile

3.7 Processing Logic

Commit/Rollback Strategy: Each BAPI call is followed by BAPI_TRANSACTION_COMMIT(WAIT='X') on success or BAPI_TRANSACTION_ROLLBACK on error. Each revision + network + WBS chain is committed independently — a failure on one revision does not roll back or affect processing of others.

STEP 1 — Fetch Eligible Revisions:

SELECT REVNR REVTY REVBD REVED IWERK VAPLZ VAWRK AUFNR OBJNR PSPEL FROM T352R INTO TABLE lt_revisions WHERE REVNR IN s_revnr AND REVTY IN s_revty AND REVBD IN s_revbd AND REVED IN s_reved AND IWERK IN s_iwerk AND VAPLZ IN s_vaplz AND VAWRK IN s_vawrk AND ZZ_ESLOT_START IN s_eslots AND ZZ_ESLOT_END IN s_eslote.

If lt_revisions is empty → message ZPM_REVCOMP 009, EXIT.

STEP 2 — Filter by Status (REL) and Age:

For each revision: read JEST WHERE OBJNR = T352R-OBJNR AND INACT <> 'X' AND STAT = 'I0002' (REL — confirmed from TJ02T). Also check: REVED <= SY-DATUM – P_DAYS (default 60). Remove revisions not meeting both conditions.

STEP 3 — Check Linked Notifications and Orders:

For each remaining revision:

• Read DIWPS_RV_CR WHERE WPID = REVNR → collect NOTIFID (TYPE QMNUM, CHAR 12) and ORDER_NO (TYPE AUFNR, CHAR 12).
• For each NOTIFID: Read QMEL-OBJNR (TYPE QMOBJNR, CHAR 22) WHERE QMNUM = NOTIFID. Read JEST WHERE OBJNR = QMEL-OBJNR AND INACT <> 'X'. Check STAT = 'I0072' (NOCO).
• For each ORDER_NO: Read AUFK-OBJNR (TYPE J_OBJNR, CHAR 22) WHERE AUFNR = ORDER_NO. Read JEST WHERE OBJNR = AUFK-OBJNR AND INACT <> 'X'. Check STAT = 'I0046' (CLSD).
• If ANY notification is NOT NOCO or ANY order is NOT CLSD → skip revision, log ZPM_REVCOMP 002.

STEP 4 — Close Revision:

Call /AXONEBX/GET_REV_CLOSE with I_REVNR = revision REVNR (TYPE REVNI, CHAR 8), I_WERKS = revision IWERK (TYPE IWERK, CHAR 4). Check return for errors. Success → log ZPM_REVCOMP 001. Error → log ZPM_REVCOMP 010 with BAPI message text.

STEP 5 — Process Networks:

Read T325R WHERE REVNR = closed revision REVNR → get network AUFNR. For each network:

• Read T325R WHERE AUFNR = network AUFNR AND REVNR <> current revision → get other linked revisions.
• For each other revision: check CLSD via JEST (STAT = 'I0046').
• If ALL other revisions CLSD → Call BAPI_BUS2002_SET_STATUS:

ParameterDirectionTypeValue
NUMBERIMPORTINGBAPI_NETWORK_LIST-NETWORK (NW_AUFNR, CHAR 12)Network AUFNR
SET_SYSTEM_STATUSIMPORTINGBAPI_SYSTEM_STATUS-SYSTEM_STATUS (CHAR 4)'TECO'
RETURNEXPORTINGBAPIRETURN1Check TYPE for E/A

Then call BAPI_TRANSACTION_COMMIT(WAIT='X'). Log ZPM_REVCOMP 003.
• If ANY revision NOT CLSD → skip, log ZPM_REVCOMP 004.
• If revision has no linked network → log ZPM_REVCOMP 005.

STEP 6 — Process WBS Elements:

For each TECO'd network: Read AUFK WHERE AUFNR = network AUFNR → get PSPEL (TYPE PS_PSP_ELE, NUMC 8). Read AUFK WHERE PSPEL = same PSPEL AND AUFNR <> current network → get other linked networks. Check each TECO via JEST (STAT = 'I0045').

If ALL TECO → Call BAPI_BUS2054_SET_STATUS:

ParameterDirectionTypeValue
I_WBS_SYSTEM_STATUSTABLESBAPI_WBS_MNT_SYSTEM_STATUSWBS_ELEMENT = PSPEL (PS_POSID, CHAR 24), SET_SYSTEM_STATUS = 'TECO'
RETURNEXPORTINGBAPIRETURN1Check TYPE for E/A

Then call BAPI_TRANSACTION_COMMIT(WAIT='X'). Log ZPM_REVCOMP 006.
If ANY network NOT TECO → skip, log ZPM_REVCOMP 007.

STEP 7 — Email Notification (Plant ECE2 only):

If revision IWERK = 'ECE2' AND WBS was TECO'd:

• Read SO15 distribution list for EC FI recipients.
• Compose email per MO-0595 template.
• Call SO_NEW_DOCUMENT_ATT_SEND_API1:

ParameterDirectionType
DOCUMENT_DATAIMPORTINGSODOCCHGI1 (subject, doc_size, obj_descr)
PACKING_LISTTABLESSOPCKLSTI1
CONTENTS_TXTTABLESSOLISTI1 (email body per MO-0595)
RECEIVERSTABLESSOMLRECI1 (from SO15 dist list)

Handle exceptions: TOO_MANY_RECEIVERS, DOCUMENT_NOT_SENT, DOCUMENT_TYPE_NOT_EXIST, OPERATION_NO_AUTHORIZATION, PARAMETER_ERROR, X_ERROR, ENQUEUE_ERROR — all caught and logged as warnings. Does not affect status changes.

STEP 8 — Display Log:

Collect all messages in lt_log. Foreground: CL_SALV_TABLE ALV with color coding. Background: WRITE to spool for SM37 review.

4. No data: ZPM_REVCOMP 009 + EXIT.
5. Independent chains: Error on one revision does not roll back or affect others.
